1. Pengertian Bootstrap
    Bootstrap adalah framework yang membantu kita membuat website dengan lebih mudah dan cepat. Di dalamnya sudah tersedia banyak desain siap pakai, seperti tombol, navbar, form, dan card, jadi kita ga perlu mebuat semuanya dari awal.
2. Memasang Bootstrap
    Ada tiga cara untuk menggunakan Bootstrap, yaitu:
    - CDN, yaitu menggunakan link Bootstrap dari internet tanpa perlu mengunduh filenya.
    - Download Bootstrap, yaitu mengunduh file Bootstrap lalu memasukkannya ke dalam folder project.
    - Package manager, yaitu memasang Bootstrap menggunakan alat seperti npm.

3. Grid dan Breakpoint
    Grid digunakan untuk mengatur posisi dan ukuran konten website agar terlihat rapi, misalnya membagi halaman menjadi beberapa kolom.

4. Class Bootstrap (10 poin)
    Berikut beberapa class Bootstrap beserta kegunaannya:
    - container untuk mengatur area konten website.
    - bg-success untuk memberikan warna latar belakang hijau.
    - text-white untuk membuat tulisan berwarna putih.
    - btn btn-primary untuk membuat tombol berwarna biru.
    - card untuk membuat kotak yg berisi konten.
    - d-flex untuk mengatur posisi elemen agar lebih mudah.
    - shadow-lg untuk memberikan bayangan pada elemen.

5. Gambar Responsif
    Agar gambar bisa menyesuaikan ukuran layar, kita bisa menggunakan class img-fluid pada tag gambar. Dengan begitu, gambar akan menyesuaikan lebar area tempatnya berada dan tidak mudah keluar dari batas kontainer.
